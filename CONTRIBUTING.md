# Contributing to TeleConnect Live Chat Pro

Thank you for your interest in contributing to **TeleConnect Live Chat Pro**! We welcome contributions from developers worldwide.

---

## 🛠️ How to Contribute

1. **Fork the Repository:**
   Click the "Fork" button at the top right of this repository.

2. **Clone your Fork:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/teleconnect-telegram-livechat-wordpress.git
   cd teleconnect-telegram-livechat-wordpress
   ```

3. **Create a Feature Branch:**
   ```bash
   git checkout -b feature/amazing-feature
   ```

4. **Follow WordPress Coding Standards:**
   - Always sanitize inputs with `sanitize_*` functions.
   - Always escape outputs with `esc_*` functions.
   - Always verify nonces on form submissions.

5. **Commit & Push:**
   ```bash
   git commit -m "feat: add support for voice messages"
   git push origin feature/amazing-feature
   ```

6. **Open a Pull Request:**
   Submit your pull request to the `main` branch with a clear explanation of what your code changes accomplish.
